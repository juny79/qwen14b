# Qwen2.5 A100 MIG 실습 진행 보고서 v8

- **보고서 버전:** v8 (v1~v7 보존, VL 정성 점검과 잔여 작업 추가)
- **기준 시점:** 2026-10-09, 사용자가 공유한 VL 추론 출력 및 validation annotation 구조 검사 기준
- **프로젝트:** G-NAHPM-40 A100 MIG 40GB 오픈소스 AI 실습
- **현재 진행:** 5단계 성능 측정 완료. 6단계 VL 단일 이미지 추론 및 출력 내부 일관성 정성 점검 완료. 어댑터 파일은 확인됐지만 4단계 베이스/QLoRA 비교 평가는 아직 실행 결과 미확인.
- **검증 범위:** 모델 출력과 annotation 구조는 사용자 공유 터미널 출력에 근거한다. 이미지 원본을 직접 시각 확인하지 않았고, 정답 텍스트 레이블도 없어 이미지에 대한 사실 정확도는 검증하지 않았다.

> v1~v7은 과거 상태의 스냅샷으로 보존한다. 완료 후 최종 보고도 새 버전으로 추가한다.

## 2. VL 정성 점검

대상: `datasets/images/val/drp.en_ko.in_house.selectstar_000307.jpg`; 모델: `Qwen/Qwen2.5-VL-7B-Instruct`; 최대 할당 GPU 메모리 15.80 GiB.

| 점검 항목 | 결과 | 의미 |
|---|---|---|
| JSON 파싱 | 통과 | 모델 응답에서 JSON 객체를 추출해 파싱함 |
| 필수 필드 존재 | 통과 | merchant/date/total/currency/items 출력됨 |
| 금액 내부 산술 | 일치 | 6,000×3=18,000; 5,000×1=5,000; 품목 금액 합 23,000으로 total과 일치 |
| 영수증 이미지와 문자열 일치 | 미확인 | 직접 시각 대조 및 텍스트 정답 레이블 없음 |
| 필드별 정답 정확도 | 산출 불가 | `val.json`은 words 좌표(points), orientation, language를 기록하며 전사 문자열/영수증 필드 정답은 확인되지 않음 |

따라서 이 평가는 **출력 형식과 내부 산술 일관성 확인**으로 제한한다. 상호명·날짜·품목이 이미지에 정확히 적혀 있다고 검증하거나 OCR 정확도가 높다고 주장하지 않는다. 품목 합계가 총액과 맞는 것도 이미지 사실성을 보증하지 않는다.

## 3. 검증 범위상 미완료 항목

`lab4_qlora/eval_adapter.py`는 베이스 모델과 LoRA 적용 모델을 같은 3개 요청으로 비교하도록 작성되어 있다. 작업 공간에 어댑터 파일은 있으나 해당 스크립트의 실행 출력과 통과 수는 공유·확인되지 않았다. 실습 순서의 학습 결과 비교까지 마무리하려면 GPU에 다른 작업이 없을 때 이 평가를 실행하고 결과를 기록해야 한다. 세 사례는 데모용이며 통계적 성능 향상을 입증하지 않는다.

## 4. 다음 작업 및 완료 기준

1. `nvidia-smi`로 GPU가 비어 있는지 확인한다. vLLM/VL/기타 GPU 작업이 있으면 평가를 동시에 시작하지 않는다.
2. `.venv-infer`에서 `python lab4_qlora/eval_adapter.py`를 실행한다. 출력의 베이스/어댑터 JSON 및 분류 결과를 보존한다.
3. 결과에서 JSON 파싱 여부와 기대 category 일치 수를 표로 정리한다. 어댑터가 베이스보다 낫지 않더라도 결과를 그대로 기록하고 성능 향상을 주장하지 않는다.
4. 완료 후 GPU 반환을 확인하고, 4단계 평가 결과와 6단계 정성 점검 한계를 함께 새 버전 최종 보고서에 기록한다.

4단계 평가 결과가 확인되기 전에는 전체 계획을 완전히 마무리했다고 표시하지 않는다.
