- **보고서 버전:** v5 (v1~v4 보존, 서버 종료 및 GPU 반환 확인 추가)
- **기준 시점:** 2026-10-09, 사용자가 공유한 vLLM 종료 로그와 종료 후 `nvidia-smi` 출력 기준
- **프로젝트:** G-NAHPM-40 A100 MIG 40GB 오픈소스 AI 실습
- **현재 진행:** 0~3단계 완료(v2 기록), 4단계 어댑터 산출물 확인·평가 미확인(v3 기록), 5단계 벤치마크 완료 및 vLLM 서버 종료 확인. 6단계 VL은 미실행.

## 2. 벤치마크 서버 종료 결과

- 벤치마크 요청 후 vLLM 로그에서 `/v1/chat/completions`에 대한 HTTP 200 응답이 확인됐다.
- 마지막 집계 로그에서는 `Running: 0 reqs`, `Pending: 0 reqs`, GPU/CPU KV cache 사용량 0.0%였다. 서버는 요청 처리가 끝난 뒤에도 약 4분가량 더 실행되다가 14:24:09에 사용자가 Ctrl+C로 종료했다.
- 종료 시 vLLM 엔진 프로세스에서 `KeyboardInterrupt: MQLLMEngine terminated` traceback과 PyTorch ProcessGroupNCCL 미정리 경고가 출력됐다. 이는 Ctrl+C 중단 경로에서 기록된 경고다. 동시에 FastAPI 로그는 `Shutting down`, `Waiting for application shutdown`, `Application shutdown complete`를 출력했다.
- 종료 직후(14:24:37) `nvidia-smi`에서 MIG 장치는 40448 MiB 중 16 MiB 사용으로 표시됐고 `No running processes found`였다. 따라서 공유된 출력 기준으로 서버가 종료되고 GPU 작업이 반환된 것으로 판단한다.
- vLLM 종료 로그에 예외·경고가 있기는 하지만, 애플리케이션 종료 완료와 GPU 프로세스 부재가 확인됐다. GPU 작업이 계속 남았거나 측정 요청이 실패했다는 증거는 없다. 다음 실행에서 문제가 재현될 경우에만 프로세스 그룹 정리 경고를 별도로 조사한다.

5단계 수치 및 측정 한계는 `docs/progress_report_v4.md`에 기록했다. 주요 수치는 동시성 1·2·4 각각 26.159, 50.734, 50.557 aggregate output tokens/s이며, 각 수준 4개 요청이 모두 성공했다. 결과 CSV로 공유된 경로는 `logs/bench_results_20261009_141927.csv`이다.

## 4. 다음 단계

1. 이번 종료 확인으로 알려진 vLLM 서버와 GPU 프로세스는 남아 있지 않다. 다음 실행 직전에 `nvidia-smi`를 다시 확인하고, 다른 사용자의 프로세스가 있으면 종료하지 않는다.
2. 다음 계획인 6단계 VL 이미지 분석을 진행할 때는 개인정보가 없는 이미지 파일을 사용한다. 이미지가 준비되지 않았으면 샘플을 직접 생성·선택하기 전까지 실행을 보류한다.
3. `nvidia-smi`에서 MIG 메모리 반환이 확인되지 않거나 본인 실습 프로세스가 남아 있으면 새 GPU 작업을 시작하지 않고 상태를 먼저 확인한다.
