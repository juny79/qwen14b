# Qwen2.5 A100 MIG 실습 진행 보고서 v6

- **보고서 버전:** v6 (v1~v5 보존, VL 단일 이미지 실행 결과 추가)
- **기준 시점:** 2026-10-09, 사용자가 공유한 VL 추론 출력 기준
- **프로젝트:** G-NAHPM-40 A100 MIG 40GB 오픈소스 AI 실습
- **현재 진행:** 0~3단계 완료(v2 기록), 4단계 어댑터 파일 확인·평가 미확인(v3 기록), 5단계 벤치마크와 서버 종료 확인(v4·v5), 6단계 VL 단일 검증 이미지 실행 성공. 전체 VL 성능 평가는 미실행.
- **검증 범위:** 아래 실행 결과는 사용자가 공유한 터미널 출력에 근거한다. 이 보고서 작성 과정에서 이미지 자체나 정답 주석 파일과 모델 출력을 독립 대조하지 않았다.

> v1~v5는 이전 진행 시점의 스냅샷으로 보존한다. 후속 실험은 새 버전 문서에 추가한다.

## 2. 6단계 실행 설정 및 자원

- 데이터 split: `val` (평가용으로 `test` split을 보존)
- 입력: `datasets/images/val/drp.en_ko.in_house.selectstar_000307.jpg`
- 모델: `Qwen/Qwen2.5-VL-7B-Instruct`
- 코드: `lab6_vl/vl_receipt.py`
- 최대 이미지 변: 1024 pixels; 처리 이미지 크기 로그: 628×1024
- 실행 환경: `.venv-infer`, A100 MIG 3g.40gb
- GPU 실행 전 `nvidia-smi`: MIG 40448 MiB 중 16 MiB 사용, 실행 중 프로세스 없음
- 최대 할당 GPU 메모리: **15.80 GiB**

## 3. 모델 출력

모델이 추출한 JSON은 다음 값이었다.

- 상호명: `클라시커커피`
- 날짜: `2021-12-15`
- 총액: `23000`
- 통화: `원`
- 품목:
  - `오레그랏세`: 단가 6000, 수량 3, 금액 18000
  - `애플크럼블`: 단가 5000, 수량 1, 금액 5000

JSON 파싱은 성공했다. 품목 금액의 산술 합계는 23000원으로 모델이 출력한 총액과 내부적으로 일치한다. 다만 이것은 출력 자체의 일관성만 확인한 것이며, 이미지의 실제 글자와 정답 주석에 맞는지 검증한 결과는 아니다. 날짜·상호명·품목 인식 정확도도 독립 확인 전까지 확정하지 않는다.

## 4. 로그 경고 및 해석

- Transformers image processor의 `use_fast` 미지정 경고가 있었다. 현재 저장된 느린 processor를 사용했고 추론은 완료됐다. 향후 Transformers 버전에서 기본 처리기가 바뀌면 결과에 작은 차이가 생길 수 있다는 경고다.
- 생성 설정에서 `do_sample=False`인데 `temperature=1e-6`이 설정됐다는 경고가 있었다. sampling이 꺼져 있어 해당 temperature는 생성에 사용되지 않는다. 이번 요청은 완료됐지만, 재현성·경고 정리를 위해 generation config를 점검할 수 있다.
- 두 경고 모두 이번 실행의 JSON 파싱 실패나 CUDA 오류를 뜻하지 않는다. 모델 응답은 반환됐고 GPU 최대 할당은 15.80 GiB였다.

## 5. 결론 및 후속 검증

이번 실행으로 VL 모델 로딩, 이미지 입력 처리, 결과 생성, JSON 파싱까지 **단일 이미지 파이프라인을 확인**했다. 이는 전체 데이터셋의 OCR 정확도나 일반화 성능을 확인한 것은 아니다.

정량적인 성능을 주장하려면 별도 기준에 따라 일부 `val` 이미지의 정답 주석과 상호명·날짜·총액·품목을 필드별로 비교해야 한다. 공개·제공된 `test` split은 평가 계획에 따라 보존한다. 운영·정산에 쓰기 전에는 중요한 날짜와 금액을 원본 이미지와 사람이 대조한다.
