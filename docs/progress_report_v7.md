# Qwen2.5 A100 MIG 실습 진행 보고서 v7

- **보고서 버전:** v7 (v1~v6 보존, validation 주석 구조 확인 추가)
- **기준 시점:** 2026-10-09, 사용자가 공유한 `val.json` 구조 검사 결과 기준
- **프로젝트:** G-NAHPM-40 A100 MIG 40GB 오픈소스 AI 실습
- **현재 진행:** 0~5단계는 이전 버전 보고서 참고. 6단계는 VL 단일 이미지 추론 및 JSON 파싱 성공. Validation 주석 구조를 확인했으나, 의미 텍스트 정답은 없어 상호명·날짜·금액 정확도를 자동 채점할 수 없음.
- **검증 범위:** 주석 구조와 예시 레코드 정보는 사용자가 공유한 검사 출력에 근거한다. 이미지 및 레이블 내용에 대한 시각적 독립 확인은 수행하지 않았다.

> 이전 보고서는 각 시점의 스냅샷으로 보존한다. 후속 실험은 새 버전으로 기록한다.

## 2. `val.json` 주석 구조

사용자 실행으로 확인한 파일 및 레코드 정보:

- 주석 파일: `datasets/jsons/val.json` (33,394,190 bytes)
- 상위 구조: `images` 객체 아래에 이미지 파일명을 키로 둔 레코드
- `drp.en_ko.in_house.selectstar_000307.jpg` 레코드:
  - `words`: 81개 번호형 주석 (`0001` 등)
  - `img_w`: 785
  - `img_h`: 1280
- 81개 `words` 전체의 필드 유형 집계:
  - `points`: list
  - `orientation`: string 또는 null
  - `language`: list 또는 null
- 검사한 주석에는 인식된 문자열, 상호명, 날짜, 총액 또는 품목 이름 필드가 나타나지 않았다. 따라서 현재 파일로는 모델이 생성한 의미 JSON과 정답 문자열을 필드별로 직접 비교할 수 없다.
- 이 구조는 단어 영역 좌표 및 방향·언어 등 시각적 텍스트 영역 주석으로 보인다. 다만 제공된 출력만으로 좌표 기준/순서와 전체 데이터셋의 모든 추가 필드 의미를 확정하지 않는다.

검사용 스크립트 `scripts/inspect_val_annotation.py`는 파일명 키 검색과 단어별 필드 집계를 수행한다. 처음 버전은 파일명을 값에서만 찾는 오류가 있었으며, 수정 후 공유한 검사 결과에서 대상 이미지가 정상적으로 한 건 검색됐다.

## 3. 평가 가능 범위와 제한

- 현재 `val.json`만으로 자동 평가할 수 있는 것은 (데이터셋의 좌표 정의를 추가 확인한 경우) 모델 출력에서 얻은 텍스트 영역과 주석의 `points` 간 검출 위치 비교 정도다.
- 기존 VL 코드는 JSON 의미 필드(merchant/date/total/items)를 출력하고 주석은 word-level geometry를 제공하므로, 두 결과의 표현 단위가 다르다. 별도 OCR transcript나 receipt-level 정답이 없으면 필드 추출 정확도, CER/WER를 계산할 수 없다.
- 이를 보완하려면 해당 데이터셋의 공식 문서에서 `points` 의미와 좌표 convention을 확인하고, OCR 텍스트 정답이 포함된 대응 annotation을 찾거나, 일부 이미지에 대해 사람이 전사한 정답을 별도로 만들어야 한다.
- 사람 정답을 만드는 경우 개인정보·라이선스·보관 정책을 확인하고, 가능한 한 validation 표본에만 작업한다. `test` split은 최종 평가 계획이 정해질 때까지 보존한다.

## 4. 다음 작업

1. 이 주석만으로 영수증 필드 정확도를 채점했다고 주장하지 않는다.
2. 목적이 파이프라인 데모라면 다른 `val` 이미지 몇 장에서 추론을 반복하고, 출력은 원본 이미지와 수동 대조하는 정성 평가로 기록한다.
3. 정량 평가가 목표라면 먼저 데이터셋 공식 정의와 텍스트 전사 레이블의 존재를 확인한다. 없으면 소규모 사람 전사 기준셋을 별도 제작하거나 transcript 포함 영수증 데이터셋으로 평가 계획을 바꾼다.
4. 단어 상자 위치 평가를 원할 경우 좌표 해석 및 Qwen-VL의 word-level box 출력 방식이 마련되기 전에는 해당 지표를 계산하지 않는다.
